# StorePilot 靠谱店铺导航

输入一个商品或芯片型号，一键整理 **阿里巴巴 / 淘宝 / 立创商城 / 云汉芯城** 的靠谱店铺，点击卡片直接跳转到对应平台店铺。

**核心特性：**
- 🔍 搜索一个商品 → 四个平台的靠谱店铺一目了然
- ⏩ 点卡片直达平台店铺 / 无预置数据时一键直达平台搜索
- 🔄 **数据实时更新**：改 GitHub 上的 `data/shops.json` 即生效，无需重新部署

---

## 如何更新店铺数据（实时更新教程）

数据全部存在 `data/shops.json`，本站每次加载都从本仓库的 `main` 分支实时拉取。

**加一个商品的店铺** → 复制下面这段，粘贴到 `entries` 数组里，改内容，提交：

```json
{
  "id": "my-product",                     // 唯一标识，别重复
  "keywords": ["我的商品", "别名1", "alias2"],
  "stores": [
    { "platform": "lcsc", "name": "靠谱店铺名", "tag": "旗舰店 · 现货", "url": "https://店铺链接", "demo": false },
    { "platform": "alibaba", "name": "另一家店", "tag": "工厂 · 认证", "url": "https://..." }
  ]
}
```

**改一个店铺** → 找到对应 entry，改 `stores` 里的链接或名字。

**删一个店铺** → 删掉对应的那一条 store 对象。

**去掉「示例」徽标** → 示例数据都带 `"demo": true`，换成真实店铺后删掉这个字段即可。

### platform 固定 key（不能改）

| key | 平台 |
|-----|------|
| `alibaba` | 阿里巴巴（1688） |
| `taobao`  | 淘宝 / 天猫 |
| `lcsc`    | 立创商城 |
| `ickey`   | 云汉芯城 |

### 平台直达搜索（无需数据也能用）

任何搜索词即使没有预置店铺，也会在页面上提供四个平台的**搜索直达链接**，点击直接打开该平台的搜索结果页。各平台搜索地址模板在 `assets/js/app.js` 的 `PLATFORMS` 里。
