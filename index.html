📦 店铺数据如何「实时更新」？

  1. 数据源在 GitHub 仓库 shop-hub/data/shops.json，本站每次加载都会拉取最新版本；
  2. 你要加店铺 / 改链接 / 删店铺：直接编辑该 JSON 并提交，刷新本站即生效，无需重新部署；
  3. JSON 结构见 shops.json 与 README，照着复制一条改就行；
  4. 带「示例」徽标的数据为演示数据，替换为真实店铺后可去掉 demo 标记。
